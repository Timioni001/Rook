The fix

A handled failure that leaves no trace is indistinguishable from no failure.

The retries were already there. What was missing was the honesty: a failure the engine survived closed its span green.

  rook/obs.py
+ def failed(self, kind, msg, retrying):
+     set_status(ERROR, kind)
+     rook.error.kind   = kind
+     rook.retrying     = retrying
+     output.value      = msg

  no span exports an empty
  input or output any more
