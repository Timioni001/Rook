# Entire workflow

**Status: not used in this build (team decision, 2026-10-10).**

The Entire CLI (0.11.4) was installed and checked in the build environment. The team then chose not to enable `entire enable` on these coding sessions, so this repository has no Entire checkpoints. None will be created after the fact, and the history won't be rewritten to suggest otherwise.

Using Entire later would mean following https://hack.entire.io/neathacks-2026 (`entire enable --agent <agent>`, commit, `entire checkpoint list`, `entire status`) on new work, and recording the checkpoint URL here.
